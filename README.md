# Célveren portfolio

My developer portfolio — a place to share what I’m building and working on next.

Currently featuring **Lightning**, a Discord moderation bot, and **Adamel**, a vehicle maintenance app for Apple devices.

The site is built with HTML, Tailwind CSS, and a little JavaScript, with scenic artwork and support for light and dark mode.

## Local development

Open `index.html` directly for a quick look, or serve it locally:

```sh
python3 -m http.server 4174 --bind 127.0.0.1
```

The site will be at [localhost:4174](http://127.0.0.1:4174/). Card-style experiments live in [previews/index.html](previews/index.html).

To rebuild the styles with Node.js installed:

```sh
npm ci
npm run build
```

Use `npm run watch` while editing. Page content lives in `index.html`, styles in `input.css`, and small interactions in `script.js`. `styles.css` is generated by the build.

## Docker

To build and run locally with Docker Desktop:

```sh
docker compose up --build -d
```

Open [localhost:8080](http://localhost:8080). Run the same command after edits to rebuild, and `docker compose down` to stop. Docker builds its own stylesheet without updating the local `styles.css`.

If port 8080 is busy, use `CELVEREN_PORT=8081 docker compose up --build -d`.

## Maintenance notes

Before publishing, check mobile and desktop layouts, links, images, keyboard navigation, and reduced-motion behavior.

Server setup and automatic deployment are documented in [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md). For a manual upload, include `index.html`, `styles.css`, `script.js`, and `assets/`.

Artwork sources and usage notes are in [docs/ASSETS.md](docs/ASSETS.md). No open-source license is currently assigned to this repository.
