## Coding Guidelines

For JavaScript files, indent with 4 spaces per nesting level.

### HTML

For HTML files, use a coding indentation of 2 spaces per nesting level.

When engaging with tags in their 1st nest, separate the end of the closing tag with 2 lines.

For example,
```
<html>
<head>

# Meta tags here

</head>

<p>Hello World</p>
```
